What this is

Що це таке

Что это такое

A marketplace repository. You add it once to your agent CLI, then install plugins by name. Each plugin is a self-contained bundle of slash commands, sub-agents, hooks, skills and — where it needs persistent state — its own MCP server.

Репозиторій-маркетплейс. Додаєте його до свого агентського CLI один раз, далі ставите плагіни на ім'я. Кожен плагін — самодостатній набір слеш-команд, субагентів, хуків, скілів і — там, де потрібен постійний стан — власного MCP-сервера.

Установка

Add the marketplace once, then install whatever you need. Nothing is installed globally — every plugin is opt-in.

Додайте маркетплейс один раз, далі ставте те, що потрібно. Нічого не ставиться глобально — кожен плагін підключається окремо.

Добавьте маркетплейс один раз, дальше ставьте что нужно. Ничего не ставится глобально — каждый плагин подключается отдельно.

Crashlytics

Production Продакшн Продакшн v4.4.4 Claude Code + Codex

Turns a Crashlytics issue id into a report you can act on: what broke, which commit introduced it, who should fix it, and a before/after patch. Android and iOS, platform auto-detected from project config.

Перетворює id іссюї в Crashlytics на звіт, з яким можна працювати: що зламалось, який коміт це приніс, хто має чинити, і патч до/після. Android та iOS, платформа визначається з конфігу проєкту автоматично.

Превращает id иссюи в Crashlytics в отчёт, с которым можно работать: что сломалось, какой коммит это принёс, кому чинить, и патч до/после. Android и iOS, платформа определяется из конфига проекта автоматически.

Pipeline

Пайплайн

Пайплайн

Four steps, each its own sub-agent, ending in a deterministic quality gate — the report is rejected if the forensics section is missing or the fix is not code-level.

Чотири кроки, кожен — окремий субагент, наприкінці детермінований quality gate: звіт відхиляється, якщо немає секції форензики або фікс не на рівні коду.

Четыре шага, каждый — отдельный субагент, в конце детерминированный quality gate: отчёт отклоняется, если нет секции форензики или фикс не на уровне кода.

Plugin Cross Port

Beta v0.10.1 Claude Code + Codex

The reason the rest of this marketplace is dual-target. It converts a plugin between Claude Code and Codex formats, then keeps both targets reconciled as the source changes — including the parts that cannot be derived mechanically.

Причина, чому решта цього маркетплейсу dual-target. Конвертує плагін між форматами Claude Code і Codex, а далі тримає обидві цілі узгодженими, поки джерело змінюється — включно з тим, що неможливо вивести механічно.

Причина, по которой остальной маркетплейс dual-target. Конвертирует плагин между форматами Claude Code и Codex, а дальше держит обе цели согласованными, пока источник меняется — включая то, что нельзя вывести механически.

# one-shot conversion, interactively
> Convert plugins/obsidian-tracker to Codex

# deterministic marketplace reconciliation
$ cross_port.py marketplace attach --source claude-code
$ cross_port.py marketplace sync
$ cross_port.py marketplace check

# semantic adaptations: plan first, then apply atomically
$ cross_port.py plugin adapt plugins/example
$ cross_port.py plugin adapt plugins/example --apply

На вхід — запис доповіді, на вихід — вертикальні кліпи з субтитрами й готові тексти для соцмереж. Whisper для транскрипту, Opus для вибору моментів, ffmpeg для нарізки.

На вход — запись доклада, на выход — вертикальные клипы с субтитрами и готовые тексты для соцсетей. Whisper для транскрипта, Opus для выбора моментов, ffmpeg для нарезки.

> /clip-maker ~/Downloads/my-talk.mp4

▸ transcribe      Whisper (local or API)
▸ find-moments    Opus ranks quotable segments from the transcript
▸ smart-crop      vision-based speaker detection → 9:16
▸ cut             ffmpeg + burned-in subtitles
▸ copy            captions for Shorts / Reels / TikTok

# or run a single stage
> /transcribe ~/Downloads/my-talk.mp4
> /find-moments ~/Downloads/transcript.json

Після клонування увімкніть git-хуки — вони ганяють тести плагінів перед кожним пушем.

После клонирования включите git-хуки — они гоняют тесты плагинов перед каждым пушем.

$ git clone https://github.com/IvanLutsenko/awac-ai-agent-plugins
$ git config core.hooksPath .githooks
